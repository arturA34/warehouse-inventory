# Печатные формы для согласования

В разделе «Отчёты» есть проекты ТОРГ-12 и ИНВ-19. Предпросмотр и PDF используют один снимок данных. Примеры ниже построены на вымышленных складских данных.

| Проект | Данные из системы | Поля для согласования |
| --- | --- | --- |
| [ТОРГ-12](torg-12-draft.pdf) | Номер и дата проведения, статус, склад или маршрут, артикул, название, единица, количество, цена и сумма исходного движения. | Реквизиты поставщика и получателя, основание, НДС, ответственные лица и подписи. |
| [ИНВ-19](inv-19-draft.pdf) | Склад, даты и идентификатор ревизии, товар, учёт и факт, излишки и недостачи с отдельными суммами по проведённым актам. | Реквизиты организации, основание ревизии, состав комиссии и подписи. |

Для согласования нужно утвердить назначение форм, состав обязательных реквизитов и источник их заполнения. Шаблоны помечены как проекты.
